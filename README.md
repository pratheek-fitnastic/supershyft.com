# Supershyft - Precision Health Solutions

A modern, responsive website for Supershyft, a precision health platform that combines Bio AI technology with personalized health insights.

## 🌐 Features

- **Responsive Design** - Optimized for mobile, tablet, and desktop
- **Bio AI Technology Section** - Showcase of advanced health analysis technology
- **How It Works** - Clear visualization of the Supershyft process
- **Testimonials** - Client feedback and success stories
- **Interactive Animations** - Smooth scroll-based animations using GSAP
- **Video Content** - Integrated video demonstrations
- **Contact Forms** - Easy customer inquiries

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** None (static HTML site)
- **Animations:** GSAP ScrollTrigger
- **Carousel:** Swiper.js
- **Utilities:** Bootstrap, jQuery, AOS (Animate On Scroll)

## 🚀 Getting Started

### Prerequisites
- Python 3.x (for simple local HTTP server)
- Modern web browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/pratheek-fitnastic/supershyft.com.git
```

2. Navigate to the project directory:
```bash
cd supershyft.com
```

3. Start a local HTTP server:
```bash
python -m http.server 8080
```

4. Open in browser:
```
http://localhost:8080/index.html
```
