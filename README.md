# Supershyft - Precision Health Solutions

A modern, responsive website for Supershyft, a precision health platform that combines Bio AI technology with personalized health insights.

## Features

- Responsive design for mobile, tablet, and desktop
- Bio AI technology showcase and interactive section flows
- "How It Works" storytelling and timeline interactions
- Testimonials and trust sections
- Interactive animations (GSAP, Swiper, scroll effects)
- Video-first content blocks and card/cube visual components

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Animations: GSAP ScrollTrigger, Swiper.js
- Utilities: Bootstrap, jQuery, AOS

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/pratheek-fitnastic/supershyft.com.git
```

2. Go to project folder:

```bash
cd supershyft.com
```

3. Start local server:

```bash
python -m http.server 8080
```

4. Open:

```text
http://localhost:8080/index.html
```
